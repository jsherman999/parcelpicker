How to read this:
  • ✅ PASS — the browser fetched the data cross-origin. This endpoint works in an all-in-browser build from this origin.
  • ❌ FAIL — the fetch was rejected. For security the browser reports CORS blocks and network errors identically as TypeError: Failed to fetch. Open DevTools → Console to see the precise reason: a line containing "blocked by CORS policy: No 'Access-Control-Allow-Origin' header" means CORS; anything else (DNS, TLS, offline) is a plain network failure.
Origin matters: some servers only allow specific origins. For a trustworthy result, serve this file from the origin you intend to deploy to (e.g. python3 -m http.server for localhost, or your real static host). Avoid file:// — its origin is null and behaves differently.
